## 🛠️ Tecnologias Utilizadas

* **SGBD:** PostgreSQL
* **Ferramenta de Gestão:** DBeaver
* **Controle de Versão:** Git & GitHub

## 🚀 Como Executar o Projeto

1. Certifique-se de ter o **PostgreSQL** instalado e em execução.
2. Acesse a pasta da [**Sprint 4**](./Sprint-4/) para obter o script SQL mais recente (`script_sprint4.sql`).
3. Conecte-se ao banco via DBeaver e execute os passos do guia contido no README da pasta.
